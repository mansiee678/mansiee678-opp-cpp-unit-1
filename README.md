About the Chapter

This README contains the C++ programs for Chapter I – Basics of C++ Programming, based on the uploaded practical programs. The chapter covers fundamental C++ concepts including data types, conditional statements, loops, arrays, functions, classes and objects, constructors and destructors, static members, inline functions, and friend functions. These concepts form the foundation for understanding Object-Oriented Programming and advanced C++ features.

List of Programs
1. Basic Data Types

Demonstrates the use of fundamental C++ data types such as int, char, and float, along with output statements.

2. If-Else Statement

Demonstrates decision making using the if-else construct to determine whether a student has passed or failed based on marks.

3. Loop and Array

Demonstrates the use of arrays and a for loop to store and display multiple values efficiently.

4. Functions

Demonstrates user-defined functions, function declaration, definition, and function calling for performing arithmetic operations.

5. Class and Object

Demonstrates the creation of a class, data members, member functions, and object initialization in C++.

6. Constructor and Destructor

Demonstrates automatic invocation of constructors and destructors during object creation and destruction.

7. Static Member

Demonstrates the use of static data members shared among all objects of a class and accessed using the class name.

8. Inline Function and Friend Function

Demonstrates an inline member function and a friend function that can access private members of a class.
